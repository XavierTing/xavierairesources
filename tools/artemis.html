ARTEMIS

Lets your AI assistant use a real Android phone the way you would.

Category

Connections

Made by

Google

You'll need

An Android phone with USB debugging switched on (a developer setting that lets a computer control the phone over a cable), or a phone simulator on your computer; a Mac, Windows or Linux computer with Git, the tool that downloads code (a Mac offers to install it the first time; on Windows get it free from git-scm.com); and an API key, a password-like code from an AI service such as Gemini, Claude or OpenAI that lets a program use it and bills you. The start script installs the other helper programs for you

Why use ARTEMIS?

If you are building a phone app with an AI coding assistant, the assistant can write the code but cannot pick up a phone and check that the login screen works. Testing by hand means tapping through the same screens after every change. ARTEMIS lets the assistant do it. You give an instruction such as open Settings, find Battery and tell me the level, and it looks at the screen, decides what to tap, and repeats until the job is done, usually taking three to five seconds a step. It records screenshots and the phone's own error log as it goes, so you can see what happened. It connects to Claude Code, Codex and other assistants through MCP, a standard plug that lets an AI assistant use other programs, and it also has a web page where you watch the phone's screen live. It works only with Android for now, and every step sends a picture of the phone's screen to the AI service you chose.

When should you use ARTEMIS?

Reach for it when you are building an Android app and want your assistant to install it and check a flow, such as sign-up or checkout, after every change, or when you want to repeat a long series of taps across apps. Use a spare phone or a simulator rather than your personal phone: it can tap anything on the screen, and every step sends a screenshot to an outside AI service. It does not work with iPhones yet.

How do you install and use ARTEMIS?

  1. On the Android phone, open Settings, go to About phone and tap Build number seven times to reveal Developer options (the exact place varies by phone brand). In Developer options, turn on USB debugging, then connect the phone with a USB cable that carries data, not just charge. A phone simulator, a pretend phone that runs on your computer (Android Studio includes one), works too.
  2. Open the Terminal app, the window where you type commands, paste the command below and press Enter. On Windows, use PowerShell and run the same command with `.\start.bat` in place of `./start.sh`. It downloads ARTEMIS, installs what it needs and opens a setup page in your web browser. Get an API key from your AI service's website first (for Gemini, aistudio.google.com), paste it in when asked, and say yes when it offers to connect to your coding assistant, such as Claude Code.
  3. Start with a harmless job, such as `Open Settings, find Battery and tell me the current level`, typed into the setup page's task box or asked of your coding assistant, and watch the phone while it works. The setup page replays each run step by step with its screenshots, so check those rather than trusting the summary.
Paste into the Terminal app git clone https://github.com/google/artemis.git && cd artemis && ./start.sh
