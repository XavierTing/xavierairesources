Headroom

Shrinks what gets sent to the model, not the answers.

Why

A lot of what your assistant reads is filler. Command output, log files, long stretches of data. You pay for every word of it and almost none of it makes the answer better. Headroom compresses that material before it reaches the model. The project measures around 20 percent fewer tokens on coding work and between 60 and 95 percent on data files, with the same answers coming back.

When

Work that pushes a lot of output through the assistant: reading logs, handling large data files, or long runs where the context fills up and earlier detail starts falling out.

How

  1. Install it with pip. It needs Python 3.10 or newer.
  2. Pick how to run it: as a library inside your own code, as a proxy in front of the model, or as a connected tool.
  3. Carry on as normal. It compresses in the middle and the answers come back unchanged.
pip install "headroom-ai[all]"
