Why use Linear?

Work that falls out of a coding session usually needs writing down somewhere, and that somewhere is normally a different window you have to go and find. This wires your assistant straight into Linear, where many software teams track their issues. It can create issues, change their status, manage projects and search across workspaces. The plugin itself is thin, a small piece of configuration pointing Claude Code at Linear's own server, which is where the work actually happens.

When should you use Linear?

Teams already on Linear. It earns its place right at the end of a working session, when there are three follow-ups you would otherwise mean to write up later and then not.

How do you install and use Linear?

  1. Install the plugin from the official marketplace.
  2. Sign in to Linear when it asks. The plugin holds nothing itself, it points at Linear's own server.
  3. Ask in plain words, along the lines of opening an issue for the thing you just found.
Paste into the Terminal app claude plugin install linear@claude-plugins-official
