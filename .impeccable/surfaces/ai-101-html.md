# Surface: ai-101.html (+ 101.css, 101.js, assets/101/)

Scope: the "AI 101" tab — the Artificial Intelligence 101 course as the site's second page. Visitor mode: Read — a beginner must understand 56 AI terms, not adopt tools; the back half turns understanding into operational literacy for building digital products with agentic tools (Claude Code, Codex, Antigravity, Kimi).

Audience & job: people new to AI (colleagues, students, LinkedIn readers), arriving from the log tab or a shared link; "explain the words everyone keeps using — then the words you need to build." A tertiary student with zero AI knowledge must follow every sentence. Success: they finish a chapter and can define the words in it.

Content: 56 terms across 9 chapters + cover (expanded 2026-08-12 from the 27-term port, on the syllabi of four Nick Saraev 2026 courses + classic AI-foundation curricula). Chapters 06 "The parts of a web app" (web-stack literacy) and 07 "Debugging and security" (build loop, debugging, security five, audits, prompt injection) are Builder-tagged. Fixed entry anatomy: display word → gold bar → What it is → For example → analogy → diagram (universal since 2026-08-13: 56 dg-* images, one per entry) → In one line. Three interactives (context meter, flight walkthrough, tool filter), fix table, recap dl, Singapore UTAP note. New plates: 08-frame (stack), 09-lighthouse (ship). Art style (user-directed 2026-08-12, superseding the flat-poster diagrams and engraved plates): the whole set — 56 diagrams AND 9 plates — is a friendly hand-drawn sketchnote style (wobbly ink outlines, curved arrows, hand-lettered caps, after Nick Saraev's course slides), still strictly in the five-colour linen palette so recolor.py's dark pass keeps working.

Constraints: hand-owned page — generate-seo.mjs never touches it (it only adds the URL to sitemap/llms.txt). Duplication is deliberate for no-JS/crawlers: cover TOC = chapmenu list; each "In one line" repeats in the recap; chapend titles are hand-written — SYNC comments mark each pair. Fixed contents-row anatomy (2026-08-13, replacing title + question + description): number → title → one description → one labelled word list → time, every row the same, each deck a size step down from the last. The title names the chapter's subject as a noun phrase, deliberately NOT a What/How/When question phrase (tried 2026-08-13 and reverted): a column where four titles open on "What" and three on "How" forces the reader past a function word before the subject appears. Each title must read identically on all seven surfaces it appears on: chapbar dot, chapmenu, cover row, section data-title, plate h2, both neighbours' chapend cards, recap header. The cover has no contents heading, so the h1 carries id="h-cover" + tabindex="-1" as the section's accessible name and 101.js's focus target. Cluster labels (.c-gl) follow the same rule as the titles: a noun naming the group ("Model types", "Blind spots", "Automation"), never "What it is" / "How you ask". This is the cover list ONLY — the 56 entries keep their "What it is" / "For example" / "In one line" field labels, which are the AGENTS.md entry anatomy and must not be swept up in a find-and-replace. The .c-words--grouped label track is a fixed 10.5em, not auto, because each row is its own grid and auto sizing staggers the word columns down the page; measure a label's fit with a Range, since .c-gl stretches to the track and its box width always reads back as the track width. .c-num carries font-variant-numeric: tabular-nums — Montserrat's digits are proportional, so without it 01 and 09 size that auto column differently and shift every row body a few px out of true. Chapter router + interactives live in 101.js; deep links (#e-mcp) open their chapter.

Chosen direction: Signal Field inherited whole (see DESIGN.md), in both themes, with Daylight (the default) restoring the course's original linen world — the markup ships the assets/101/light/ art and theme.js swaps to the dark set only for Night; tokens cascade through the aliases. Layout: centred 1240px column; at >=1240px each article.entry splits prose (.entry-flow) beside its analogy+diagram rail (.entry-rail); the ch6 section.entry stays single-column. 101.css aliases the course's token names (--linen, --rule, --gold…) onto site tokens. Course keeps its own devices in-world: 96×4 gold bar, glass chapter plates with recoloured art tiles, gold-fill numerals, chaptered navigation (sticky glass bar desktop / floating bottom bar mobile). Artwork recoloured by assets/101/recolor.py — the ember #d97757 there must match --ember in 101.css.

Memorable moment: the context meter turning ember at "turn 7"; the chapter plate with its engraved tile.

Unresolved: og:image reuses the site card (a course-specific 1200×630 could replace it); print sends dark diagrams to paper (plates are hidden, diagrams kept for meaning).
